## 👋 About

```yaml
name:        Sonic
role:        independent dev / opensource maintainer
languages:   [Rust, Go, .NET (C#), TypeScript, Swift]
stack:       cross-platform native, networking, low-level I/O, UI
platforms:   [Windows, Linux, macOS]
philosophy:  "ship the binary, write the README, make it work"
```

I build cross-platform desktop tools and networking infrastructure — usually in Rust when the binary needs to be small, fast, and dependency-free. Most of my projects are open-source, MIT-licensed, with CI-built releases for Win / Linux / macOS.

I write up the engineering side of the work on [Habr](https://habr.com/ru/users/by-sonic/articles/) and [Дзен](https://dzen.ru/sonicdev).
